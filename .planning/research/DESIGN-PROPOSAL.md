## 一、品牌核心理念

### 品牌名
**墨途** / **Motu** (mò tú)

### 命名释义
- **墨** — 书写之始，文明之源。代表代码即书写，会话即墨迹。
- **途** — 行者之路，探索之旅。代表每次 AI 编程会话都是一段旅程。
- **Motu** — 音译简写，简短有力，国际通用。发音联想：motion（流动）、motif（主题）。

### 品牌故事

> 程序员如行者，代码如笔墨。
> 每一次与 AI 的对话，都是在未知领域的探索——翻过 Bug 的山岭，穿过架构的丛林，最终在代码的原野上留下清晰的足迹。
> 墨途，就是你的编程行纪。
> 它不只记录你走了多远，更帮你记住沿途的发现，提炼旅途的智慧，将每一段经验锻造为可复用的工具。
> 笔走千行，途载万智。

### Slogan 体系

| 类型 | 中文 | 含义 |
|------|------|------|
| 主 Slogan | **笔走千行，途载万智** | 代码如笔墨书写千行，旅途承载万般智慧 |
| 产品定位 | AI 编程会话的探索手账 | 明确产品品类和价值 |
| 功能版 | 记录·提炼·锻造 | 三步核心能力：记录会话、提炼经验、锻造 Skill |
| 极简版 | 墨迹所至，皆为资产 | 强调核心价值——每段会话都有价值 |

### 品牌人格
- **气质**：古雅诗意，温润如玉
- **态度**：匠人心态，精雕细琢
- **调性**：东方文人 × 现代工程师
- **情感**：安静、从容、深沉但不疏远

## 二、视觉识别系统

### 2.1 Logo 设计

#### 主体 Logo
```
意象：一缕水墨笔触，从左上向右下自由流动
      笔触中部自然过渡为代码大括号 { }
      整体形成优雅的流线型符号
      右下角点缀朱砂红印章（小方块，内含"途"字篆体）

简洁版：纯水墨笔触 + 小印章
```

#### Logo 规范
- **标准色**：墨色 `#1a1a1a` + 朱砂红 `#c23a2e` 印章
- **单色版**：纯墨色 / 纯白色（反白）
- **最小尺寸**：16px × 16px（favicon）— 仅保留笔触符号
- **安全区域**：Logo 四周保留至少 1/4 高度的留白

#### App Icon (PWA/桌面)
- 圆角方形底色：宣白 `#f5f0e8`
- 中央：墨色笔触符号
- 右下角：朱砂红小印章
- 整体感觉：一张宣纸上的墨迹题签

#### Favicon
- 简化为笔触 + 印章的核心图形
- 16px/32px 尺寸仅显示笔触弧线 + 印章点

### 2.2 色彩体系

#### 主色调
| Token | 名称 | 色值 | 用途 |
|-------|------|------|------|
| `--ink` | 墨色 | `#1a1a1a` | 主文字、Logo 笔触 |
| `--ink-light` | 淡墨 | `#3d3d3a` | 次要文字 |
| `--ink-wash` | 游墨 | `#5e5d59` | 辅助文字、占位符 |
| `--rice` | 宣白 | `#f5f0e8` | 主背景（纸质） |
| `--rice-medium` | 素宣 | `#ebe6da` | 次级背景 |
| `--rice-dark` | 旧纸 | `#e2dcd0` | 三级背景、分隔 |

#### 品牌强调色
| Token | 名称 | 色值 | 用途 |
|-------|------|------|------|
| `--cinnabar` | 朱砂 | `#c23a2e` | 主强调、印章、CTA 按钮 |
| `--cinnabar-hover` | 朱砂亮 | `#d44a3e` | 强调色悬停态 |
| `--indigo` | 靛青 | `#2c5f7c` | 用户事件、链接 |
| `--mineral` | 石绿 | `#4a7c5c` | 成功、活跃状态 |
| `--ochre` | 赭石 | `#a67c52` | 文件/工具事件 |
| `--fig` | 紫果 | `#9c4a6a` | 中断状态 |

#### 语义色
| Token | 名称 | 色值 | 用途 |
|-------|------|------|------|
| `--status-active` | 行进中 | 石绿 | 进行中的会话 |
| `--status-complete` | 已达 | 墨色淡 | 已完成的会话 |
| `--status-interrupted` | 暂歇 | 紫果 | 中断的会话 |
| `--status-failed` | 陨途 | 朱砂 | 不可恢复的会话 |

#### 深色模式
- 墨色背景体系：`#141413` → `#1e1e1c` → `#2a2a28`
- 文字变为宣白体系
- 朱砂红保持不变（深色中的暖色点缀）
- 石绿、靛青饱和度微调以保持深色中的可读性

### 2.3 字体体系

| 用途 | 字体 | 备选 | 说明 |
|------|------|------|------|
| **品牌标题** | 霞鹜文楷 (LXGW WenKai) | Noto Serif SC | 开源手写楷体，文雅有温度 |
| **正文** | Inter | system-ui | 现代、清晰、可读性强 |
| **代码/数据** | JetBrains Mono | Fira Code | 连字支持，开发者熟悉 |
| **装饰** | ZCOOL XiaoWei | — | 印章/标题装饰用 |

**字体层级**：
- H1（页面标题）：霞鹜文楷 24px / 500
- H2（区块标题）：霞鹜文楷 18px / 500
- Body：Inter 14px / 400
- Caption：Inter 12px / 400
- Code：JetBrains Mono 13px / 400
- Brand Stamp：霞鹜文楷 12px / 700（印章效果）

### 2.4 质感与纹理

#### 宣纸纹理
```css
/* 全局背景叠加宣纸纹理 */
background-image: url("data:image/svg+xml,<svg xmlns='...' width='200' height='200'>
  <filter id='n'><feTurbulence type='fractalNoise' baseFrequency='0.65' numOctaves='3' stitchTiles='stitch'/>
  <feColorMatrix type='saturate' values='0'/></filter>
  <rect width='100%' height='100%' filter='url(#n)' opacity='0.03'/></svg>");
```
- 透明度极低（2-3%），仅创造"手感触感"
- 不干扰文字阅读
- 深色模式下使用反向噪点

#### 水墨渐变
- 登录页/空状态使用水墨渐变（从墨色到透明的径向渐变）
- 模拟真实水墨在宣纸上的晕染效果

#### 装饰元素
- **缝线分隔**：虚线分隔线，模拟手工装订的线迹
- **印章效果**：朱砂红圆/方印，用于 Logo、确认标记、状态标签
- **折页效果**：卡片轻微的纸角翻折暗示
- **墨点**：细微的装饰性墨点，用于加载状态或点缀

### 2.5 图标体系

- **风格**：线性图标，线条粗细 1.5px，圆角处理
- **尺寸**：16/20/24px 三档
- **来源**：Lucide（已在使用），增加少量自定义图标
- **自定义图标**：
  - 砚台图标（品牌专用）
  - 毛笔图标（编辑/创作）
  - 印章图标（确认/验证）
  - 竹简图标（列表/记录）
  - 灯笼图标（AI 分析/洞察）

### 2.6 间距与圆角

保持现有体系，微调：
- 圆角偏向"手工裁切"感：12px → 10px（略微方正）
- 新增 `--radius-stamp: 50%` 用于印章效果
- 新增 `--radius-fold: 2px` 用于纸角翻折

## 三、UI 重构设计

### 3.1 整体布局理念

> 墨途不是"管理后台"，而是一本打开的行纪手账。

- **桌面端**：左侧书脊（侧边栏）+ 中间书页（内容区）+ 右侧批注（详情面板）
- **移动端**：单页切换，像翻阅手账的不同页面

### 3.2 登录页 — "手账封面"

**视觉设计：**
- 全屏宣纸纹理背景
- 中央大号品牌标题"墨途"，使用霞鹜文楷，下方朱砂红印章
- 产品副标题"AI 编程会话的探索手账"
- 密码输入区：极简设计，底部线条式输入框（如同在纸上写字）
- 登录按钮：朱砂红底色，白色文字，按下有"盖章"效果（scale 动画）
- 底部脚注："数据存于本地，如墨入纸，不外传"

**动效：**
- 页面加载：水墨晕染渐入效果
- 输入密码时：底部线条如墨迹延伸
- 登录成功：整个页面如翻书般过渡到主界面

### 3.3 桌面端主界面 — "三栏行纪"

#### 头部 — "书脊标题栏"
- 宣纸底色，高度 52px
- 左侧：Logo 笔触 + "墨途" 品牌名 + 朱砂红小印章
- 中间：会话统计，如 "行纪 128 篇"
- 右侧：搜索图标 + 主题切换（日/月图标切换，模拟翻页）+ 退出按钮
- 底部有一条朱砂红细线（1px），如同书脊的装订线

#### 左侧栏 — "目录"（320px，可收起至 40px）
- 顶部搜索栏：底部线条样式，如同在目录页上手写查找
- 筛选器：两个下拉选择，用缝线分隔
- 会话卡片列表（详见 3.4）
- 底部收起按钮：点击时如折叠书页般收起

#### 中间区域 — "正文"（时间线）
- 顶部显示当前选中会话标题，使用霞鹜文楷
- 时间线视图（详见 3.5）
- 无选中时显示空状态："翻开目录，选择一段行纪"

#### 右侧面板 — "批注"（320px，可隐藏）
- 会话详情（详见 3.6）
- 如同手账右侧的批注栏

### 3.4 会话卡片 — "行纪索引卡"

**视觉设计：**
- 卡片：宣白底色，轻微阴影（模拟纸张微微浮起）
- 左边缘：4px 宽的状态色条（石绿/墨色淡/紫果/朱砂）
- 标题：Inter 14px/500，最多两行，超长截断
- 分隔线：虚线（缝线风格），不是实线
- 元数据行：时间（相对时间）、分支名（等宽字体）、状态标签
- 底部指标行：工具调用数（石绿图标）、错误数（朱砂图标）、Token 数（等宽字体）

**交互：**
- 悬停：阴影加深 + translateY(-1px)（如同手指轻触纸张）
- 点击：scale(0.98) 弹簧效果（按下纸张的触感）
- 选中：左色条变宽至 6px + 底部朱砂红细线 + 阴影最强
- 进入视口：opacity 0→1 + translateY(8px→0)，错落 40ms

### 3.5 时间线 — "行纪路线"

**核心设计：垂直虚线连接所有事件节点，如同地图上的行进路线。**

**视觉设计：**
- 左侧垂直虚线（石灰色，2px，虚线间隔 6px）
- 事件节点坐在虚线上，如同路线上的地标
- 节点图标：圆形（28px），不同事件类型不同底色
  - 用户消息：靛青底色 + 用户图标
  - AI 响应：石绿底色 + 机器人图标
  - 文件操作：赭石底色 + 文件图标
  - 命令执行：灰色底色 + 终端图标
  - 错误：朱砂底色 + 警告图标
- 事件内容：标题 + 预览文本（可展开）
- 时间戳：小型文字，沿虚线排列如同页边批注

**交互：**
- 事件进入视口：从左侧滑入（translateX(-12px→0)），错落 30ms
- 展开/收起：高度弹簧动画，如同展开一张折叠的纸条
- 悬停：节点微微放大（scale 1.05）
- 加载中：虚线先出现，节点逐一"盖印"到线上

### 3.6 会话详情 — "行纪报告"

**视觉设计：**
- 顶部标题区：霞鹜文楷显示会话标题 + 状态标签（印章风格圆角矩形）
- 信息网格：
  - 时间信息行：起止时间、持续时间
  - 项目信息行：项目名、分支（等宽字体）
  - 模型信息行：AI 模型名称
- 统计卡片 2×2 网格：
  - 文件操作数、工具调用数、错误数（朱砂色高亮）、Token 数
  - 每张卡片有顶部色条（对应语义色）
  - 数值用等宽大字体突出
- 会话 ID：等宽字体代码块，虚线边框，右侧复制按钮
- 复制成功：出现朱砂红"✓"印章效果

### 3.7 移动端 — "行纪口袋本"

#### 设计理念
iOS PWA 应该像一个精心设计的口袋笔记本 App，每一帧都像在翻阅实体手账。

#### 布局结构
- 顶部：品牌标题栏（48px + safe-area-top）
  - 左侧 Logo + "墨途"
  - 右侧搜索 + 主题切换
- 中间：内容区域（根据 Tab 切换）
- 底部：三 Tab 导航栏（56px + safe-area-bottom）
  - "目录"（会话列表）、"路线"（时间线）、"报告"（详情）
  - 使用 Lucide 图标 + 中文标签
  - 激活态：图标变为朱砂红 + 底部朱砂红小圆点

#### Tab 切换动效
- 内容区：新内容从右侧滑入，旧内容向左滑出
- Tab 指示器：小圆点平滑滑动到新位置
- 过渡时间 250ms，弹簧参数 stiffness=300, damping=30

#### iOS PWA 特殊处理
- 启动画面：宣纸背景 + 墨途 Logo + 水墨晕染动效
- 状态栏：`apple-mobile-web-app-status-bar-style: default`
- 安全区域：顶部和底部正确处理 safe-area-inset
- 触摸反馈：所有可点击元素 44px 最小触摸区域
- 滚动：`overscroll-behavior: none` 防止橡皮筋效果
- 返回手势：利用 iOS 的边缘滑动返回

### 3.8 空状态 — "空白页"

- 设计为一张空白宣纸的意象
- 中央：柔和的墨色图标（不是实心方块，而是线描风格的图标）
- 标题："尚无行纪"（使用霞鹜文楷）
- 引导文案："运行 `motu scan` 开始你的第一段行纪"
- 命令块：虚线边框，如同便签条
- 背景：淡墨渐变装饰

### 3.9 搜索栏 — "页边检索"

- 极简设计：仅有底线，无完整边框
- 底线如同用尺子画的参考线
- 聚焦时底线变朱砂红，如同用红笔画线标记
- 搜索图标用毛笔/砚台主题替换放大镜
- 支持中文 IME，保持现有防抖逻辑

## 四、交互与动效体系

### 4.1 动效哲学

> 墨途的动效如同水墨在宣纸上的自然行为——
> 墨入纸时由浓渐淡，笔抬起时留下飞白，
> 一切自然而然，不刻意也不造作。

### 4.2 动效库

使用 **Motion for React** (v12.x) 作为动效引擎：
- 安装：`npm install motion`
- 提供 `<motion.div>`、`<AnimatePresence>`、弹簧物理等能力
- 支持 `useReducedMotion()` 无障碍适配

### 4.3 核心动效规范

#### 页面/内容切换
| 场景 | 动效 | 时长 | 缓动 |
|------|------|------|------|
| 桌面会话选择 → 详情 | 详情面板从右滑入 + 淡入 | 250ms | spring(300,30) |
| 移动 Tab 切换 | 内容左右滑动 + 淡入淡出 | 250ms | spring(300,30) |
| 侧边栏收起/展开 | 宽度过渡 + 内容渐隐 | 200ms | ease-out |
| 登录 → 主界面 | 全页面水墨渐变过渡 | 400ms | ease-in-out |

#### 卡片交互
| 场景 | 动效 | 时长 | 缓动 |
|------|------|------|------|
| 悬停 | translateY(-1px) + 阴影加深 | 200ms | ease-out |
| 按下 | scale(0.98) | 100ms | spring(400,25) |
| 选中 | 左色条滑入 + 底线出现 | 150ms | ease-out |
| 进入视口 | opacity + translateY(8px) | 200ms | ease-out，错落 40ms |
| 退出 | opacity + translateY(-8px) | 150ms | ease-in |

#### 时间线交互
| 场景 | 动效 | 时长 | 缓动 |
|------|------|------|------|
| 节点进入 | translateX(-12px→0) + 淡入 | 200ms | ease-out，错落 30ms |
| 展开/收起 | 高度弹簧动画 | 250ms | spring(300,30) |
| 悬停节点 | scale(1.05) | 150ms | ease-out |
| 加载 | 虚线先现，节点逐一"盖印" | 30ms/个 | spring(500,30) |

#### 按钮与控件
| 场景 | 动效 | 时长 | 缓动 |
|------|------|------|------|
| 按钮悬停 | 背景色渐变 + 微阴影 | 150ms | ease-out |
| 按钮按下 | scale(0.97) | 80ms | spring(500,30) |
| 复制确认 | 朱砂红"✓"印章效果弹出 | 200ms | spring(400,25) |
| 主题切换 | 日/月图标旋转过渡 | 300ms | ease-in-out |
| 下拉选择 | 面板从触发位置向下展开 | 200ms | spring(350,28) |

#### 加载状态
- **骨架屏**：使用与实际内容相同的布局，浅色纸纹闪烁动画
- **时间线加载**：虚线先出现，节点依次"盖印"落位
- **搜索加载**：搜索栏底部线条脉动

### 4.4 微交互细节

- **选中会话**：卡片左色条从 0 宽度滑出到 4px，伴随微妙的阴影变化
- **复制 Session ID**：复制按钮变为朱砂红印章 "✓"，然后恢复，全程 600ms
- **切换深色/浅色**：如同日落/日出的渐变过渡，而非硬切
- **滚动到列表底部加载更多**：底部出现加载行，用墨迹淡入效果
- **错误状态**：朱砂红色调微微闪动一次（而非持续红色）
