| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-01-05 | Information Disclosure | Environment | accept | Phase 1 has no network exposure. API key handling (D-20) deferred to Phase 2+ when AI features are used. |
