<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Export output -> Filesystem | Exported Markdown/JSONL may contain sensitive data (API keys, internal paths) |
| Config files -> App | User-edited TOML config is semi-trusted |
| CLI args -> Export | session_id and output paths are user-controlled |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-11 | Information Disclosure | Markdown export | mitigate | Export directory outside project by default (EXPT-04). Auto-create .gitignore (EXPT-05). Print warning about sensitive content in unsafe export. |
| T-01-12 | Tampering | Config file writes | mitigate | Validate config file path is within expected directories. Validate values are reasonable paths. |
| T-01-13 | Information Disclosure | JSONL export | accept | JSONL export is raw content by design. User explicitly chose this format. Watermark footer included per EXPT-06. |
| T-01-14 | Tampering | Resume command | accept | Resume command is displayed to user who decides whether to run it. No automatic execution. |
</threat_model>
