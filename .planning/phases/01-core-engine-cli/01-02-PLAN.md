<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filesystem -> Parser | JSONL files from ~/.claude/projects/ are untrusted external input (may be malicious, corrupted, or actively being written) |
| Config files -> App | TOML config files are semi-trusted (user-edited) |
| Environment vars -> App | CCCMEMO_* env vars are semi-trusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-06 | Denial of Service | JsonlParser | mitigate | 10MB line hard cap (D-03). Streaming parser never loads full file. |
| T-01-07 | Tampering | SQL queries in indexer | mitigate | All queries use rusqlite params! macro. Never format SQL strings with user data. |
| T-01-08 | Information Disclosure | Log output during scan | mitigate | tracing::debug for file content. Never log raw transcript content (D-21). Only log session IDs, file paths, error types. |
| T-01-09 | Tampering | File paths from discovery | mitigate | Canonicalize all paths. Validate paths are under ~/.claude/projects/ before processing. |
| T-01-10 | Denial of Service | ScanBookmark hash comparison | accept | sha2 comparison is constant-time for security but DoS via crafted files is low risk for local tool. |
</threat_model>
